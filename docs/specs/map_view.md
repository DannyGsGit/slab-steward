# Map View Spec

Trail line color and glow color strategy:
- Trails are colored according to IMBA difficulty (Purple- Unrated, Easy- Green, Medium- Blue, Hard- Black, Very Hard- Red)
- When using the "Map Controls" highlight toggles to emphasize trails, those trails matching the highlight conditions get a golden yellow glow
- Trails that have been selected get a teal glow
- Trails with staged changes are get a glow according to the difficulty level (if set). If difficulty is not set, the trail gets a purple glow.
- Trails that are de-emphasized with dashed lines continue to be dashed, albeit with the color schemes described above
