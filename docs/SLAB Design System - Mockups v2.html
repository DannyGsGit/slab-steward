Design System — Visual Mockups v2 · July 2026
This supersedes the color direction in SLAB Design System — Nav & Slider Pane v1. That doc's July mockups were wireframes — their teal/cream chrome wasn't meant to carry forward. The palette below instead bridges the moody, dark-forest / gold identity from the original brand mockups and SLAB wordmark with the navy chrome and gold icon accents already live in the current app's map screen. The map itself — basemap, trail line colors, star trailheads — is treated as fixed and untouched; every mockup below reuses it as-is. Only the surrounding chrome (rails, tab bars, search fields, the slider pane, and its six contexts) is new.

Two open items from v1 are resolved here: control-panel icon order is now consistent across web and mobile (Discover, Search, Record, Favorites, Account), and mobile's missing Settings tab is folded into a menu row inside Account. Gear Garage still has no confirmed home in this IA — flagged in the Account mock below as a placeholder.
